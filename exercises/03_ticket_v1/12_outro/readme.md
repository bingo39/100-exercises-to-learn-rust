# 传参原则

传参核心原则：
+ 小的 Copy 类型（u32, bool 等）→ 直接传值
+ 大的非 Copy 类型（String, Vec 等）→ 传引用

| 类型 | 是否 Copy | 传参建议 | 返回建议 |
|------|-----------|----------|----------|
| `u32`, `i32` 等整数 | ✅ Copy | 传值 | 返回值 |
| `bool` | ✅ Copy | 传值 | 返回值 |
| `char` | ✅ Copy | 传值 | 返回值 |
| `f64` | ✅ Copy | 传值 | 返回值 |
| `&T` 引用 | ✅ Copy | 传值 | 返回值 |
| `String` | ❌ 非 Copy | 传引用 `&str` | 返回引用 `&str` |
| `Vec<T>` | ❌ 非 Copy | 传引用 `&[T]` | 返回引用 |
| `Order` | ❌ 非 Copy | 传引用 `&Order` | 返回引用 |
**理由：**
✅ 传值（复制）成本极低（4 字节）
✅ 代码更简洁
❌ 传引用反而增加复杂度（8 字节指针）
